# 与 Clash / v2rayN / CMFA 的对照与优化建议

- 日期：2026-11-14
- 对照对象：Clash for Windows / Clash Verge、v2rayN、Clash Meta for Android（CMFA）
- 我们的版本：v2.3.1（root 透明网关，5 个 Tab）

---

## 1. 定位差异（先明确边界）

| 维度 | Clash / v2rayN | CMFA | 我们 |
|---|---|---|---|
| 形态 | 桌面客户端 | Android VpnService | **Android root 网关** |
| 流量接管 | 系统代理 / TUN | VpnService | iptables REDIRECT + redir-port |
| 服务对象 | 本机 | 本机 | **本机 + 热点 / 局域网设备** |
| 规则编辑 | 改 profile YAML | 改配置 / override | 自定义规则注入 + 热重载 |

结论：**系统代理、TUN、按应用代理这三类功能我们不做**（架构不同）；其余可对齐。

## 3. UI 展示建议

### 3.1 概览

| 现状 | 建议 |
|---|---|
| 大电源键 + 状态 + 当前节点 + 流量图 + 统计 | 顶部加一行**快捷模式 chips**（规则/全局/直连），不用进设置 |
| 当前节点只读 | 点击可跳转代理页并定位到该分组 |
| 流量图 60 秒 | 增加「今日流量」累计（本机记录，按天重置） |
| 无快捷更新入口 | 订阅有更新时显示小红点，点击直接更新 |

### 3.2 代理

| 现状 | 建议 |
|---|---|
| 分组 chips + 搜索 + 排序 + 列表 | 增加「隐藏不可用」开关；节点长按菜单：复制 / 测速 / 设为全局首选 |
| 延迟徽章 | 改为「延迟条」：颜色 + 长度直观对比 |
| 失败徽章 | 保留 |
| 单列列表 | 可选「紧凑双列」模式，一屏看更多节点 |

### 3.3 连接

| 现状 | 建议 |
|---|---|
| 列表 / 表格 / 图形 | 表格增加点击表头排序（流量/时间/主机） |
| 最近设备 chips | 点击 chip 过滤该设备 |
| 图形拓扑 | 保留；增加「仅看某设备」过滤 |

### 3.4 规则

| 现状 | 建议 |
|---|---|
| 顶部汇总 + 自定义/订阅双视图 | 自定义规则改**拖拽排序** |
| 添加对话框 | 类型选择改下拉（6 个 chip 占空间）；目标支持搜索 |
| 无模板 | 加「常用模板」：绕过局域网、常用域名直连、广告拦截 |

### 3.5 设置

| 现状 | 建议 |
|---|---|
| 分组卡片 + 导航行 | 加**设置搜索**（项多时有用） |
| 诊断页 | 增加「日志导出」「配置导出」 |
| 订阅页 | 显示名称、节点数、上次更新时间（已有时间） |

## 4. 性能与效率

| 项 | 现状 | 优化 |
|---|---|---|
| 连接轮询 | 页面可见时 1s | 空闲时降为 2–3s，有流量时 1s |
| 概览统计轮询 | 3s | 可与连接轮询合并，减少请求 |
| 规则应用 | 重写 config + 重载（断连接） | 可选 rule-provider 热更新（改动大） |
| 状态读取 | 部分走 shell（gateway.conf） | 缓存，仅在变更后重读 |
| APK 体积 | 42.9MB（含 geodata） | 可选：geodata 按需下载（牺牲离线） |
| 日志 WS | 打开页面才连 | 保持现状即可 |

## 5. 优先级建议

### P0（体验提升明显、成本低）

1. 概览加「规则/全局/直连」快捷 chips
2. 通知栏加操作按钮（停止网关 / 打开 App）
3. Android 快捷设置磁贴（QS Tile）开关网关
4. 订阅显示名称 + 节点数

### P1（常用功能补齐）

5. 代理页「隐藏不可用节点」+ 节点长按菜单
6. 规则「常用模板」+ 拖拽排序
7. 日志搜索 + 导出
8. 今日流量统计（本地累计）
9. 备份/恢复（规则 + 设置导出）

### P2（锦上添花）

10. 多订阅 profile
11. 节点收藏/置顶
12. 连接表格排序
13. 多语言
14. 图形拓扑按设备过滤

---

## 6. 明确不做

| 功能 | 原因 |
|---|---|
| 系统代理 / TUN / 按应用代理 | 架构是 root 网关，非 VpnService |
| 规则命中统计 | 内核不提供 |
| 在线编辑完整 YAML | 风险高，已有自定义规则与只读快照 |
| override/merge/script | 复杂度高，收益低 |
| 规则在线测试 | 无内核接口，无法准确模拟 |
