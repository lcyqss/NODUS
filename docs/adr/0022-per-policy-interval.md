# ADR 0022：每设备延迟调度间隔

- 状态：已接受
- 日期：2026-11-16

## 背景

全局延迟调度间隔对所有设备一致，但不同设备对切换实时性要求不同（例如电视盒子可以 5 分钟，手机需要 30 秒）。

## 决策

1. DevicePolicy 增加 scheduleIntervalSec，0 表示跟随全局。
2. GatewayService 固定每 15 秒 tick 一次 evaluateRouting；由仓库按设备计算是否到期：
   - interval = 设备覆盖值 > 0 ? 覆盖值 : 全局 policyIntervalSec
   - 距上次评估不足 interval 则跳过
3. 评估成功后记录该设备时间戳；策略删除/新增不影响其他设备。
4. 设备策略编辑页增加「调度间隔（秒，0=跟随全局）」。
5. IP 跟随仍使用独立固定间隔，不受此设置影响。

## 后果

- 不同设备可用不同评估频率。
- tick 粒度 15 秒；最小有效间隔 30 秒。
- 全局设置仍作为未覆盖设备的默认值。
