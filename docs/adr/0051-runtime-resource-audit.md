# ADR 0051：运行时内存与重试审计

- 状态：已接受
- 日期：2026-11-16

## 修复

1. GatewayService 的自动更新、策略同步、延迟调度循环增加启动守卫，避免 onStartCommand 重复调用时叠加循环。
2. GatewayEvents 保存网络回调引用，stop() 注销回调并取消 scope；Service onDestroy 调用。
3. 连接页设备历史限制为最近 200 台，避免 Map 永久增长。
4. 连接页轮询失败时指数退避 2s → 30s；成功后恢复 2s。
5. 首页流量/内存 WebSocket 使用 2s → 30s 指数退避重连。
6. OkHttp WebSocket 增加 20s ping；logFlow 在失败/关闭时结束 Flow。
7. 首页今日流量落盘从每 10 条消息改为最多每 60 秒一次。
8. Shell 输出限制 256KB；Shell/API/订阅下载重新抛出协程取消，不吞掉取消。
9. 订阅全部更新增加 busy 防止重复触发。

## 仍存风险

- mihomo /connections 返回的连接列表本身没有应用层上限，极端连接数仍可能造成一次较大的 JSON/列表内存峰值。
- 订阅下载没有硬性大小上限。
- 后台手动更新与自动更新仍可能并发下载；安装阶段有 Mutex，下载阶段没有。
- 连接页邻居解析每 10 次轮询执行一次，属于固定频率。
