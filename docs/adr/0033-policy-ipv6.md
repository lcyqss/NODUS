# ADR 0033：设备策略 IPv6 源地址

- 状态：已接受
- 日期：2026-11-16

## 决策

1. `PolicyRuntime` 增加 `ipv6`，与 `ip` 并列；设备在线判断改为 `ip != null || ipv6 != null`。
2. 源地址解析同时读取 IPv4 ARP 与 IPv6 邻居表；ULA/公网 v6 参与策略，`fe80` 排除。
3. mihomo 不支持 `SRC-IP-CIDR6`，统一生成 `SRC-IP-CIDR`：
   - IPv4：`/32`
   - IPv6：`/128`
4. 已应用映射改为 `v4|v6` 组合键，进程重启后从配置反推。
5. 任一启用策略设备离线时，跳过本次配置写入，保留现有策略块，避免把离线设备的规则清空。

## 后果

- 同一 MAC 可同时生成 IPv4/IPv6 两条源规则，指向同一设备组。
- IPv6 设备策略依赖已开启的局域网 IPv6 代理；未开启时只有 IPv4 规则。
- 设备卡片会同时显示 v4/v6 地址（如有）。
