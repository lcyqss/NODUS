# ADR 0039：对已连接客户端补发单播 RA

- 状态：已接受
- 日期：2026-11-16

## 背景

Android/iOS 只在连接时发送 Router Solicitation。若 IPv6 代理在客户端已连接后才开启，客户端不会再发 RS；部分客户端又不处理 AP 的多播 RA，因此一直只有 fe80，必须“忘记网络/重连”才能拿到 ULA。

## 决策

1. 6ra 每次周期发送时：
   - 继续发多播 RA
   - 读取 ip -6 neigh show dev <if> 的 fe80 邻居
   - 对每个邻居发送单播 RA
2. 单播 RA 使用客户端 link-local 作为目的地址和 checksum 目的地址。
3. 周期 5 秒，客户端无需重连。

## 后果

- 已连接客户端在开启 IPv6 代理后几秒内即可获得 ULA。
- 仍保留 RS 响应作为快速路径。
- 周期读取邻居表有少量开销，但只在 IPv6 代理开启时运行。
