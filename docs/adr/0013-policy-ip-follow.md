# ADR 0013：设备 IP 自动跟随与调度间隔

- 状态：已接受
- 日期：2026-11-15

## 背景

设备策略按 MAC 识别，但 SRC-IP 规则写的是当时的 IP。DHCP 续租、重连后 IP 变化会让规则失效；另外延迟调度固定 60 秒，无法按网络情况调整。

## 决策

1. 设备 IP 跟随：
   - 仓库记录本次写入配置的 policyId→IP 映射
   - 进程重启后从现有 config 的 SRC-IP 规则反推映射，避免误判
   - GatewayService 每 60 秒检查一次；映射与当前 ARP 解析 IP 不一致时重建配置并热重载，失败回滚
   - 设备离线（解析不到 IP）不触发重写，保留现有规则
2. 延迟调度间隔：
   - 设置项 policy_interval_sec，可选 30 秒 / 1 分钟 / 5 分钟
   - 仅影响延迟阈值评估；IP 跟随仍固定 60 秒
3. 两项都只改 config 文本与 API 选择，不改变内核结构。

## 后果

- DHCP 换 IP 后最多约 1 分钟自动恢复。
- 延迟切换频率可调，默认 60 秒。
- 手动改 config 不会被 IP 跟随纠正（比较对象是 ARP 解析结果，不是文件内容）。
