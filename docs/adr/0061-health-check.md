# ADR 0061：运行健康检查

- 状态：已接受
- 日期：2026-11-16

## 检查项

- DNS：向 127.0.0.1:1053 发送 A 查询，要求响应成功且有答案
- 端口：ss -ltn 中 7890 / 7892 / 9090 存在
- 代理：通过 127.0.0.1:7890 请求 http://www.gstatic.com/generate_204，要求 204/200

## 使用位置

- 设置 → 诊断 → 运行健康
- 网关启动完成后写日志 health dns=... ports=... proxy=...
- 手动刷新

## 限制

- 代理检查依赖当前节点，节点不可用时显示异常，但不能据此判断内核有问题
- DNS 是本地 1053，适合判断内核 DNS 是否可用
- 不自动因健康检查失败回退内核，避免网络问题误回退
