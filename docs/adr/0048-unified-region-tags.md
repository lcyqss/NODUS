# ADR 0048：统一标签匹配与地区预设

- 状态：已接受
- 日期：2026-11-16

## 变更

1. 删除 NodeRegions 和 NodeInfo.region。
2. 地区改为可编辑的预设标签，ID 保持 __region_*：
   - 迁移时自动写入 
odeTags
   - 现有策略表达式继续可用
   - 可编辑、可删除、可恢复默认
3. 新增统一 TagMatcher：
   - 中文/英文长词子串匹配
   - 2–3 位 ASCII 代码词边界匹配
   - 修复 Russia 命中 us、Finland 命中 in 等误判
4. 自定义标签与地区预设共用同一 include/exclude 匹配器。
5. 标签管理分为地区标签、自定义标签、内置类型。
6. 新增“恢复默认地区”。

## 迁移

SettingsStore 首次启动时写入缺失的 __region_* 预设，不覆盖用户已有同 ID 标签。

## 验证

- 现有策略仍命中香港 13、日本 25 个节点。
- 地区标签按香港、台湾、新加坡、日本……顺序显示。
- 韩国等地区标签可直接编辑。
