# ADR 0014：策略条件表达式

- 状态：已接受
- 日期：2026-11-15

## 背景

v2.15 的条件是「标签列表 AND + 单标签取反」，无法表达 (香港 ∨ 台湾) ∧ ¬vless。

## 决策

1. 条件模型改为布尔 AST：Ref / And / Or / Not；null 表示任意节点。
2. 文本语法：
   - AND：∧、&、and
   - OR：∨、|、or
   - NOT：¬、!、not
   - 括号分组；标签可用显示名或 tagId；优先级 ¬ > ∧ > ∨
3. 解析器在保存时校验；未知标签、缺括号等直接报错，不写配置。
4. 编辑器为文本框 + 标签快捷插入 + 实时命中数/错误提示。
5. 兼容旧数据：tags 列表解码为 And，{region, protocol} 解码为内置标签引用。

## 后果

- 设备策略可表达任意标签组合。
- 表达式以 AST JSON 持久化；改名不影响引用。
- 标签名含空格时需用 tagId 引用（后续可加引号语法）。
