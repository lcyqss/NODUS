# ADR 0049：标签分组折叠与内置类型说明

- 状态：已接受
- 日期：2026-11-16

## 修复

1. 节点标签页重复的“自定义标签”标题已删除。
2. 地区、自定义、内置类型三组均可点击标题折叠/展开。
3. 标题右侧显示数量，折叠状态用 ▾/▸ 表示。
4. 内置类型标题显示当前订阅类型数量。

## 内置类型

内置类型不是固定协议清单，而是从当前订阅 proxies 的 	ype 动态生成。

当前订阅：

`	ext
vless       31
hysteria2   15
`

因此只显示两个类型标签，属于正常行为；切换订阅后新增类型会自动出现。
