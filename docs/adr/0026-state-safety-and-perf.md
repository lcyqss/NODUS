# ADR 0026：策略状态安全、规则编辑校验与轻量性能优化

- 状态：已接受
- 日期：2026-11-16

## 决策

1. ppliedIps 在以下情况失效（置 null）：
   - pplyToConfig() 开始即置空；只有成功写入才重建
   - 热重载失败回滚后置空
   - IP 同步重载失败回滚后置空
   这样订阅安装/回滚后，下一次 sync 会重新判断并补写策略。
2. 规则新增/编辑：RulesViewModel.add/update 返回 Result，对话框只有成功才关闭；失败保留输入并显示错误。
3. 备份导入：
   - 按 MAC 去重策略（后出现覆盖前者）
   - 导入标签做循环引用检测，存在循环直接拒绝
4. 设备策略编辑页根布局加 imePadding()，底部操作栏不再被键盘遮挡。
5. 性能：
   - 节点目录按文件 mtime/size 缓存
   - 无策略/无阈值策略时跳过 runtime
   - 配置文本 trimEnd 后相同则跳过写盘与备份
6. 设备策略只接受 IPv4 地址：热点侧 IPv6 被拦截，只有 link-local 时视为离线，避免生成无法加载的规则并回滚。

## 后果

- 状态回滚后不会出现“策略实际没生效但 sync 认为已生效”。
- 规则校验失败不丢输入。
- 导入重复 MAC 不再产生多条 SRC-IP。
- 减少定时任务与保存时的重复 IO。
