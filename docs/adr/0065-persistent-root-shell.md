# ADR 0065：持久化 root shell

- 状态：已接受
- 日期：2026-11-17

## 问题

`ShellExecutor` 之前每条命令都启动一个 `su -c` 进程。Magisk/KernelSU 会为每次新的 root 请求显示授权提示，并且反复创建进程会带来不必要的唤醒和开销。

## 方案

- 首次 root 命令启动一个 `su -c sh` 会话
- 通过 stdin 发送命令，stdout/stderr 合并读取
- 每条命令使用唯一结束标记并带回退出码
- 命令串行执行，超时或会话退出时销毁会话，下一条命令重新建立
- 会话建立失败时回退到原有的一次性 `su -c` 实现

## 结果

- 同一个 App 进程生命周期内通常只触发一次 root 授权提示
- 后台轮询不再为每条命令创建 root 进程
- 启动、设置健康检查、策略同步等命令复用同一 shell

## 注意

- root 管理器主动结束会话、设备重启或 App 进程被杀后，需要重新建立会话并可能再次提示
- 命令仍受超时控制；超时会销毁会话
