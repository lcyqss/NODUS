# ADR 0016：标签组合（标签引用标签）

- 状态：已接受
- 日期：2026-11-15

## 背景

关键词标签能表达单层条件，但无法把多个标签组合成一个可复用的新标签，例如「香港 + vless」。

## 决策

1. NodeTag 增加可选 expr；存在时按表达式求值，否则走关键词规则。
2. 求值递归：Ref 解析到标签后，若该标签有 expr 则继续求值；用 visiting 集合防止循环导致栈溢出。
3. 保存时做循环检测（DFS），存在循环直接拒绝并提示。
4. 标签编辑器增加「组合表达式」字段（可引用其他标签/内置标签）；留空保持关键词模式。
5. 标签列表副标题显示表达式，便于区分关键词标签与组合标签。

## 后果

- 可构建「香港 ∧ vless」「流媒体 ∨ 专线」等可复用标签。
- 循环引用不会写入设置，也不会在求值时死循环。
- 表达式引用的标签被删除时，该组合标签对节点求值为 false（策略侧仍会提示缺失标签）。
