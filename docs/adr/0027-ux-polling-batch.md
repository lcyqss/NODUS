# ADR 0027：列表状态、节点定位提示与轮询降频

- 状态：已接受
- 日期：2026-11-16

## 决策

1. 设备策略卡片增加启用开关；同一 MAC 出现多条时标「重复 MAC」。
2. 代理页节点跳转：
   - 顶部显示「已定位：节点」并提供清除
   - 打开搜索或修改查询时自动清除定位提示
   - 离开代理页时消费掉未处理的跳转意图
3. 首页当前节点改为串行挂起调用，连接/节点刷新 5 秒；连接页 2 秒。
4. 备份导入使用独立 backupMessage，结果不再被页面 4 秒消息清理。
5. 标签编辑填写组合表达式时禁用关键词输入并提示「关键词将被忽略」。

## 后果

- 轮询请求减少，避免慢请求叠加。
- 节点跳转有明确状态，不会静默过滤。
- 列表可直接启停策略。
