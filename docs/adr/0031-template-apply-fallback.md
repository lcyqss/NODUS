# ADR 0031：模板套用到优先/回落条件

- 状态：已接受
- 日期：2026-11-16

## 决策

1. 模板「套用」弹窗增加模式选择：优先条件 / 回落条件。
2. 设备已有策略：
   - 优先模式：只替换 primary
   - 回落模式：只替换 fallback
   - 其余字段保持不变
3. 设备没有策略：
   - 优先模式：primary=模板，fallback 空
   - 回落模式：primary 空（任意），fallback=模板
4. 套用后返回策略列表，沿用保存/应用流程。

## 后果

- 模板可以只用于回落，不再强制覆盖优先条件。
- 仍按 MAC 去重，避免多条 SRC-IP。
