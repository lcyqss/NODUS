# ADR 0024：首页当前节点忽略设备策略组

- 状态：已接受
- 日期：2026-11-16

## 问题

设备策略生成的 __dev_* 组是顶层组（不被其他组引用）。首页选择「当前节点」时会从顶层组里挑一个，结果可能挑中 __dev_ 组，显示该设备策略的节点，而不是用户在代理页选择的良心云/自动选择。

实测：良心云切到日本专线04，首页仍显示香港高速02（__dev_ 的优先组节点）。

## 决策

1. 首页计算当前节点时排除名称以 __dev_ 开头的组。
2. 顶层组判定仍排除 GLOBAL 与嵌套组；排除后良心云成为顶层组，首页显示其当前节点。
3. 设备策略是「按设备」的出口，不作为全局当前节点展示。
4. 同一 MAC 只保留一条策略：保存新策略时按 MAC 替换旧策略，避免多条 SRC-IP 规则只有第一条生效。

## 后果

- 首页显示与代理页选择的组一致。
- 设备策略仍按 SRC-IP 生效，只是不再抢占首页展示。
- 已有重复 MAC 的旧策略不会自动删除，需要用户手动清理；之后再保存会自动合并。
