# ADR 0038：IPv6 DNS 中继

- 状态：已接受
- 日期：2026-11-16

## 问题

RA/DHCPv6 下发的 DNS 是 d00:1234::1，客户端默认查询 53 端口；
mihomo DNS 监听在 [::]:1053。之前 53 端口没有服务，客户端 DNS 全部失败，
表现为热点“无网络”。

## 决策

1. 新增 6dns 小型 DNS 中继：
   - 只绑定 d00:1234::1:53
   - UDP/TCP 转发到 127.0.0.1:1053
2. 开启 IPv6 代理时在 ULA 配置后启动；关闭时与 RA/DHCPv6 一起停止。
3. 保留 RDNSS 和 DHCPv6 下发同一个 ULA DNS。

## 后果

- 客户端 DNS 查询真正有服务响应。
- 不改变 mihomo DNS 监听，也不依赖 IPv6 NAT。
- 仅对 ULA 地址绑定，不影响 IPv4 的 dnsmasq/1053 链路。
