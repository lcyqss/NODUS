# ADR 0017：可视化条件组编辑器

- 状态：已接受
- 日期：2026-11-16

## 背景

表达式文本对普通用户不直观；线性运算符串又有优先级歧义。

## 决策

1. 条件用「条件组」表示：
   - 组内统一 AND 或 OR（且/或切换）
   - 子组表达括号
   - 标签和组都可单独取反
2. 数据结构仍为 TagExpr AST；UI 状态为 CondNode 树，双向转换：
   - And/Or → Group；Not(Ref) → 取反标签；Not(Group) → 取反组
   - 空组忽略；单子项组自动拍平
3. 默认可视化模式；右上角「高级」切到表达式文本，两种模式共用同一 AST。
4. 可视化操作不会产生语法错误；高级模式保留实时校验。

## 后果

- 常见组合（(香港∨台湾)∧¬vless）可完全点击完成。
- 复杂表达式仍可手写；切换不丢失条件。
- 组嵌套最多 3 层，避免手机屏幕过深。
