# ADR 0025：自定义规则编辑

- 状态：已接受
- 日期：2026-11-16

## 背景

自定义规则只有新增/启用/排序/删除，没有编辑入口。用户想改规则类型或值时只能删了重建。

## 决策

1. 规则行增加 ✎ 编辑操作。
2. 复用 AddRuleDialog，增加 initial 参数：
   - 有值时为「编辑自定义规则」，预填类型/值/目标/no-resolve
   - 新增时保持原行为
3. 保存调用 RuleRepository.update，保留原 id、启用状态与创建时间。
4. 修改后仍需点「应用」才会写入 config 并热重载。

## 后果

- 规则可原地修改，不再需要删除重建。
- 编辑不会改变规则排序。
