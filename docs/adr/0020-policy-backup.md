# ADR 0020：设备策略备份与恢复

- 状态：已接受
- 日期：2026-11-16

## 背景

策略、标签、模板都存于本机设置，换机/重装/调试前需要可迁移的备份。

## 决策

1. 备份 JSON：schema、app、exportedAt、policies、tags、templates。
2. 导出：读取设置中的三类数据，格式化为 JSON，可复制到剪贴板。
3. 导入：
   - 合并：按 id 合并，导入项覆盖同 id 旧项
   - 覆盖：用备份整体替换三类数据
   - 覆盖需二次确认
4. 导入成功后触发策略重建（IR 规则/组），失败只影响配置重建，不回滚设置。
5. UI 采用导出/导入两个页签，避免长表单按钮被键盘挤出。

## 后果

- 备份可跨设备迁移；标签/模板与策略一起走。
- 导入的 MAC 可能与本机设备不同，策略会显示「设备未在线」直到该设备出现。
