# ADR 0011：节点标签与设备策略条件

- 状态：已接受
- 日期：2026-11-15

## 背景

设备策略原先用「地区 + 协议」两个固定字段，地区依赖节点名识别，无法表达「包含 HK/香港/hongkong 且排除剩余流量」这类条件，也无法复用到多台设备。

## 决策

1. 引入节点标签：普通标签由「包含关键词（OR）+ 排除关键词（NOT）」描述；内置标签提供节点协议与识别地区，只读。
2. 设备策略条件由标签引用组成：多个标签默认 AND，每个标签可单独取反（NOT）。
3. 标签只存在于 App 数据层，不写入 mihomo 配置；策略求值后仍生成 __dev_* 组与 SRC-IP 规则。
4. 标签引用使用 id，改名不影响策略；删除被引用的标签时策略在 UI 上提示「标签已删除」，不生成无效配置。
5. 兼容旧策略：旧格式 {region, protocol} 自动映射为 __region_* 与 __type_* 内置标签。

## 后果

- 设备策略编辑器从两个下拉改为标签多选 + 取反。
- 标签管理页支持自定义标签 CRUD 与命中预览。
- 标签求值是内存操作，不影响订阅更新与内核重载流程。
