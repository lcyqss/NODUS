# ADR 0010：按设备选择出口（设备策略）

- 状态：已接受
- 日期：2026-11-15

## 背景

局域网/热点下有些设备需要特定出口：例如 Emby 需要香港 IP + VLESS，不可用时回落到新加坡 + Hysteria2。这类需求不属于订阅、也不属于全局代理设置。

## 决策

1. 新增「设备策略」层：以设备 MAC 为身份，保存「优先条件 + 回落条件」，条件由地区 + 协议组成。
2. App 从当前订阅缓存解析节点目录（名称/类型/地区），按条件生成独立策略组：
   - __dev_<id>_p（url-test，优先节点）
   - __dev_<id>_f（url-test，回落节点）
   - __dev_<id>（fallback）
3. 生成 SRC-IP-CIDR 规则并插在 rules 最前；自定义规则与订阅规则都在其后。
4. 组名统一 __dev_ 前缀，代理页过滤，不进入普通组列表。
5. 订阅安装/更新后重新生成；设备 IP 通过 ARP 按 MAC 解析；设备离线时该策略不生成规则，UI 标注。
6. 回滚：写入前备份 config，热重载失败恢复备份。

## 约束

- 仅在「规则」模式生效；全局/直连模式下规则被跳过，UI 需提示。
- v1 回落语义为「优先组不可用/无存活节点 → 回落组」，不按延迟阈值切换。
- IPv6 设备使用 SRC-IP-CIDR6；优先选择 IPv4 地址。
- 设备策略不依赖订阅自带的 自动选择/故障转移，避免订阅变化导致失效。
