# ADR 0018：命中节点预览与条件排序

- 状态：已接受
- 日期：2026-11-16

## 背景

组块编辑器只能看到命中数量，排查「为什么没命中」需要回代理页翻节点；条件顺序也无法调整。

## 决策

1. 「命中 N 个节点」可点击展开，列出最多 12 个节点名与协议；超出显示剩余数量。
2. 标签行与子组头增加 ↑/↓ 按钮，在所属组内移动；边界项对应箭头禁用。
3. 排序只改变 AST 子项顺序，不影响 AND/OR 语义与最终配置。
4. 预览使用与策略求值相同的标签表达式，确保所见即所得。

## 后果

- 条件调试成本降低，能直接看到匹配到的节点。
- 复杂组的阅读顺序可调整；语义不变。
