# ADR 0015：引号标签名与独立检查间隔

- 状态：已接受
- 日期：2026-11-15

## 背景

1. 标签名可能含空格或运算符，表达式里无法直接引用。
2. IP 跟随与延迟调度共用 60 秒节奏，但两者对实时性的要求不同。

## 决策

1. 表达式支持引号标签名："香港 高速"、'vless main'，支持反斜杠转义；
   打印表达式时，含空格/运算符/保留字的标签名会自动加引号。
2. 新增设置 ip_follow_interval_sec（30 秒 / 1 分钟 / 2 分钟 / 5 分钟）；延迟调度保持 policy_interval_sec（30 秒 / 1 分钟 / 5 分钟）。
3. GatewayService 用两个独立循环：IP 跟随与延迟评估互不影响。

## 后果

- 标签名可以自由包含空格。
- 高频 IP 跟随不会被迫带动高频延迟测速。
