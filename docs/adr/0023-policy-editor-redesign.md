# ADR 0023：设备策略编辑页重做

- 状态：已接受
- 日期：2026-11-16

## 背景

原编辑界面是 AlertDialog 内滚动表单：输入框高度 56dp、字段间距大，与卡片风格不协调；条件组、子组都用同一种卡片，层级关系不明显。

## 决策

1. 编辑改为全屏页面（SubPageHeader + 滚动内容 + 固定底部操作栏），不再使用弹窗内滚动。
2. 表单分四块卡片：设备 / 优先条件 / 回落条件 / 其他设置。
3. 输入框改为紧凑样式：
   - 设备选择为整行可点区域，不再用大号只读输入框
   - 备注名称用 40dp 自定义输入框
   - 延迟阈值/调度间隔用 38dp 数字框 + 单位
4. 条件组改为紧凑树形：
   - 子项前缀 ├/└ 表示层级
   - 子组使用浅色嵌套卡片 + 子组 标题
   - 标签行高度约 34dp，操作（取反/删除）右对齐
   - 添加标签/子组改为小号文字按钮
5. 底部固定：删除 / 取消 / 保存并应用，保存期间禁用。

## 后果

- 首屏能同时看到设备与两组条件，滚动距离明显减少。
- 子组与父组的归属关系一眼可辨。
- 既有功能（模板、预览、高级表达式、排序、取反）保持不变。
