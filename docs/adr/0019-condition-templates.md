# ADR 0019：条件模板

- 状态：已接受
- 日期：2026-11-16

## 背景

多台设备常共用同一套条件（如「香港 ∧ vless」），逐台重配成本高。

## 决策

1. 新增 ConditionTemplate（id/name/expr），存储在设置 condition_templates。
2. 条件编辑区提供「模板」入口：
   - 保存当前条件为模板（需当前表达式有效）
   - 列表套用到优先/回落条件
   - 删除模板
3. 模板只保存表达式 AST，不绑定设备、标签或订阅；套用时按当前标签求值。
4. 模板套用只修改编辑中的条件，仍需点「保存并应用」才写入策略。

## 后果

- 常用条件可复用；模板与标签解耦。
- 模板引用已删除标签时，命中数会变化，但不影响保存（策略侧仍会提示缺失）。
