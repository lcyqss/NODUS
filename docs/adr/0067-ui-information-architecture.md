# ADR 0067：页面信息架构调整

- 状态：已接受
- 日期：2026-11-17

## 首页

- 移除规则/全局/直连三段开关，运行模式仍在设置中调整
- 新增紧凑的“运行状态”卡：运行模式、局域网 IPv6、运行健康、内核
- 健康状态来自设置页手动检查后的缓存，首页不自动发起 root/网络检查

## 分流

- 一级入口改为“设备策略 / 规则”
- 设备策略展示启用数量和入口，不再和规则混在同一列表
- 规则保留“自定义 / 订阅规则”二级切换

## 设置

- “运行组件”拆成“内核 / Geo 数据 / 维护”三个次级分区

## 连接

- 设备筛选和拓扑标签优先显示主机名或 IP，不再回退到 MAC
- MAC 只在连接展开详情中显示一次
