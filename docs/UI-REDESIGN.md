# UI 重构方案（参考 Apple 设计 / 小火箭类应用）

- 目标：简洁、主次分明、入口不重复、设置分组清晰
- 参考：Shadowrocket（小火箭）、Surge iOS、Stash、Apple「设置 / 家庭」的信息层级
- 现状：5 Tab（概览 / 代理 / 连接 / 日志 / 设置），规则塞在日志页，订阅有两套入口（已修）

---

## 1. 核心原则

| 原则 | 做法 |
|---|---|
| 一屏一主操作 | 首页只有「开关」一个主操作，其余是状态 |
| 分组即导航 | 设置用「插入式分组列表」（inset grouped），组标题 + 行 |
| 渐进披露 | 高级项收进二级页，首屏只留常用 |
| 入口唯一 | 同一功能只保留一个入口（订阅、规则、备份） |
| 操作图标化 | 顶部工具栏用图标（测速/排序/暂停/添加），不用文字 chips |
| 少即是多 | 3 个以上选项用分段控件或菜单，不堆 chips |

## 2. 信息架构调整

### 现状问题

| 问题 | 说明 |
|---|---|
| 规则在「日志」页 | 日志与规则无关联，规则是高频功能却藏在二级 |
| 连接页承载过多 | 列表/拓扑/图形 + 排序 + 设备过滤 + 暂停，工具栏拥挤 |
| 设置层级混乱 | 订阅、网关、开关、管理混在一页，没有分组标题 |
| 首页信息密度高 | 电源 + 模式 + 节点 + 流量 + 统计挤在 2 屏 |
| 空态/错误提示风格不统一 | 有的居中有按钮，有的只有一行字 |

### 建议的 5 个 Tab

```
首页   节点   分流   连接   设置
```

| Tab | 内容 | 说明 |
|---|---|---|
| **首页** | 开关、状态、模式分段、当前节点、今日流量、连接设备数 | 只读 + 一个主操作 |
| **节点** | 分组切换、搜索、排序、测速、收藏、节点列表 | 订阅入口放右上角（跳设置） |
| **分流** | 自定义规则（拖拽）、订阅规则、模板、应用 | 从日志页独立出来 |
| **连接** | 列表 / 设备 / 图形，设备过滤，暂停 | 拓扑并入「设备」视图 |
| **设置** | 分组列表（网关 / 订阅 / 系统 / 诊断 / 关于） | 日志移到「诊断 → 日志」 |

> 备选：4 Tab（首页 / 节点 / 分流 / 设置），连接并入首页卡片点击进入。缺点是监控设备要多一步，不推荐。

### 3.1 首页

```
┌─────────────────────────────┐
│ Mihomo Gateway      [运行中] │
│                             │
│         ◯  电源环            │
│      已连接 · 2h 13m         │
│                             │
│  ┌───────────────────────┐  │
│  │ 规则 │ 全局 │ 直连     │  │  ← 分段控件
│  └───────────────────────┘  │
│                             │
│  当前节点                    │
│  🇸🇬 新加坡专线01|BGP|流媒体  ›│  ← 点击跳节点页
│                             │
│  今日流量            12.4 MB │
```

- 模式改「分段控件」，不再用 3 个 chips
- 当前节点行可点击，跳转并定位到所属分组
- 今日流量 + 曲线合并为一张卡片
- 设备数 / 连接数一行两列

### 3.2 节点

```
┌─────────────────────────────┐
│ 节点                🔍  ⚙︎   │  ← 搜索、排序菜单
│ [自动选择] [故障转移] [GLOBAL]│  ← 分组，横向可滚
│                             │
│ 当前：新加坡专线01            │
│                             │

│ ☆ 🇭🇰 香港高速02      139ms  │
└─────────────────────────────┘
```

- 排序/隐藏不可用收进右上角菜单（⚙︎）
- 测速按钮改为顶部图标（⚡）
- 延迟用「数值 + 细条」双重表达

### 3.3 分流

```
┌─────────────────────────────┐
│ 分流                        │
│ 自定义 3 条 · 启用 2 · 重复 0 │
│ [自定义] [订阅规则]   ＋  ▸应用│
│                             │
│ ≡ 🟣 DOMAIN-SUFFIX  DIRECT  │
│   example.com          ↑ ↓ ✕│
│ ≡ 🟠 SRC-IP-CIDR   DIRECT   │
│   192.168.0.0/16       ↑ ↓ ✕│
└─────────────────────────────┘
```

- 汇总收敛成一行
- ＋ 打开「添加 / 模板」菜单（ActionSheet）
- 应用为主按钮，仅在有改动时高亮

### 3.4 连接

```
┌─────────────────────────────┐
│ 连接                    ⏸ ✕ │
│ [列表] [设备] [图形]         │  ← 分段控件
│ 🔍 搜索      （全部）设备 chips│

│ 10.157.86.121  3 条  ↓1.2MB │
│  ↳ ash-speed.hetzner.com    │

```

- 设备 chips 常驻
- 暂停/全部断开用图标
- 「拓扑」和「图形」合并为「设备」视图（表格 + 图形切换在页内）

## 4. 视觉规范

| 项 | 规范 |
|---|---|
| 字体 | 大标题 28sp Bold；组标题 12sp 灰；正文 15sp；辅助 12sp |
| 卡片 | 圆角 12dp，内边距 16dp，无描边（浅色背景 + 1dp 分隔） |
| 主色 | 单一品牌色（当前紫），仅用于主按钮/选中态 |
| 图标 | 20dp 线性图标，工具栏统一 24dp |
| 控件 | 2–3 项用分段控件；4 项以上用菜单/下拉 |
| 弹窗 | 添加类用 ActionSheet/底部弹层；确认类用 AlertDialog |
| 空态 | 一行说明 + 一个主操作按钮 |
| 动效 | 页面切换 200ms 淡入；开关状态 150ms |

- 订阅管理改为集合视图 + 订阅详情页（改名/改链接/Provider/删除）
- 设置页移除自动更新与节点来源；删除 Provider 页面

- 订阅安装/更新后自动重建；代理页过滤 __dev_ 组
- 设备离线、无匹配节点时在策略卡片上标注，不生成无效配置
## 15. v2.15.0 节点标签

- 新增节点标签：包含关键词 OR + 排除关键词 NOT；内置协议/地区标签只读
- 设备策略条件改为标签组合：多个标签 AND，每个标签可单独取反
- 旧策略自动迁移为内置地区/协议标签
- 标签管理页：自定义标签 CRUD、命中节点数、示例
## 16. v2.16.0 延迟阈值回落

- 设备策略新增延迟阈值（毫秒，0=只按存活回落）
- 阈值 > 0 时根组改为 select，由 App 每 60 秒按优先组最优延迟切换优先/回落
- 应用策略后立即评估一次；阈值 1ms 实测切回落，300ms 实测切回优先
- 设备离线时保留现有策略配置，不再清空
## 17. v2.17.0 IP 跟随与调度间隔

- 设备 IP 变化（DHCP/重连）后自动重建 SRC-IP 规则并热重载
- 进程重启后从现有配置反推已生效 IP，避免重复写入
- 延迟调度间隔可选 30 秒 / 1 分钟 / 5 分钟；IP 跟随固定 60 秒
## 18. v2.18.0 标签表达式

- 设备策略条件改为布尔表达式：∧/∨/¬、括号、标签名或 tagId
- 编辑器实时显示命中节点数与语法错误；标签 chips 一键插入
- 旧 tags 列表与 region/protocol 自动迁移为表达式
- 保存时校验，错误表达式不会写入配置
## 19. v2.19.0 引号标签名与独立间隔

- 表达式支持 "标签 名" 引号写法，特殊字符自动转义
